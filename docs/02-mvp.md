# MVP

## Пользователь может

- зарегистрироваться
- создать тренировку
- добавить упражнение
- записать подходы
- завершить тренировку
- посмотреть историю
- посмотреть историю упражнения

---

## Пользователь НЕ может

- общаться
- покупать подписку
- использовать AI
- получать достижения
- использовать готовые программы тренировок
- пользоваться социальными функциями

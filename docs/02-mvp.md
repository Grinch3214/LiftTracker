# MVP

## Пользователь может

- начать тренировку без регистрации
- создать тренировку
- добавить упражнения
- записать подходы
- завершить тренировку
- посмотреть историю
- посмотреть историю упражнения
- зарегистрироваться для сохранения прогресса в облаке

---

## Пользователь НЕ может

- общаться
- покупать подписку
- использовать AI
- получать достижения
- использовать готовые программы тренировок
- пользоваться социальными функциями

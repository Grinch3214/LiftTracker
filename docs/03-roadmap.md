# Roadmap

## ✅ Milestone 0 — Foundation

**Цель**
Подготовить проект к разработке.

**Готово, когда**

- [ ] Vision написан
- [ ] Product Discovery завершен
- [ ] MVP описан
- [ ] User Flow готов
- [ ] Архитектура выбрана

---

## 🚧 Milestone 1

**Цель**
Пользователь впервые открывает LiftTracker и может полностью провести свою первую тренировку.

**Готово, когда**

- [ ] Пользователь может начать тренировку
- [ ] Можно записать подходы
- [ ] Можно завершить тренировку (автоматически будет завершаться)
- [ ] Тренировка сохранилась в истории локально

---

## ⏳ Milestone 2

**Цель**
Пользователь видит свой предыдущий прогресс.

**Готово, когда**

- [ ] Есть список тренировок
- [ ] Можно открыть тренировку
- [ ] Можно посмотреть историю упражнения

---

## ⏳ Milestone 3 — Daily Usage

**Цель**
Приложением удобно пользоваться на каждой тренировке.

**Готово, когда**

- [ ] Можно создавать свои упражнения
- [ ] Можно редактировать тренировку
- [ ] Интерфейс работает быстро и удобно на мобильном устройстве

---

## 🎉 Milestone 4 — MVP Release

**Цель**
Приложение готово к ежедневному использованию

**Готово, когда**

- [ ] Можно пользоваться приложением без критичных проблем
- [ ] Проведено минимум 10 тренировок
- [ ] Появился список улучшений для следующей версии

# LiftTracker

> Track your workouts. Build your habit.

## 📖 About

LiftTracker is a workout tracking application focused on helping people build a long-term training habit.

Unlike many fitness apps that mainly record exercises, LiftTracker aims to make users return to their next workout through a simple, distraction-free experience.

The project is currently in active development.

---

## 🎯 Vision

Our goal is to build a workout tracker that remains useful even without AI.

Artificial Intelligence is planned only as an enhancement—not as the core value of the product.

---

## 👤 Target User

People who:

- are starting to work out;
- have quit training several times before;
- want to see their progress;
- prefer simple and fast interfaces.

---

## 🚀 MVP

The first version focuses only on the essential experience:

- Create a workout
- Record exercises and sets
- View workout history
- Track exercise history

Everything else is intentionally postponed.
